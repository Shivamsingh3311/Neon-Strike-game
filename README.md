
# 🎮 Neon Strike — 2D Shooting Game

A fast-paced, neon-themed 2D arcade shooting game built using HTML, CSS, and JavaScript. Fight enemy drones, survive incoming attacks, increase your score, and beat your personal best!

## ✨ Features

- 🎯 Mouse-based aiming and shooting
- 🕹️ Smooth player movement
- 🤖 Enemy drones and increasing difficulty
- 💥 Bullets, explosions, and particle effects
- ❤️ Player health system
- 🏆 Score tracking and best-score saving
- 🌊 Wave-based gameplay
- 📱 Responsive design with mobile controls
- 🌌 Neon-inspired arcade visuals
- ⚡ No external libraries required

## 🛠️ Technologies Used

- **HTML5** — Game structure and canvas
- **CSS3** — Styling, layout, and visual effects
- **JavaScript** — Game logic, movement, collision detection, and scoring
- **Canvas API** — Rendering the game world

## 🏆 Objective

1. Destroy enemy drones.
2. Avoid enemy attacks.
3. Survive as many waves as possible.
4. Earn points and beat your highest score.

## 🧠 Game Mechanics

- **Enemy spawning:** Enemies appear as gameplay progresses.
- **Collision detection:** Bullets can hit enemies, and enemy attacks can damage the player.
- **Health system:** The player must avoid damage to survive.
- **Wave progression:** Difficulty increases as the player advances.
- **High score:** The best score is stored locally in the browser using `localStorage`.
